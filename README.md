# Portfolio | Abraão Paixão

Este é o meu portfólio profissional como Desenvolvedor Full Stack (Nível Pleno). O projeto foi construído para apresentar minha trajetória, habilidades técnicas, projetos em destaque e fornecer uma forma simples de contato.

## 🚀 Sobre o Projeto

O portfólio foi desenhado para ser leve, rápido e responsivo, focado em mostrar meus trabalhos e evolução na área da tecnologia. Todo o conteúdo dinâmico (projetos, habilidades e informações pessoais) é injetado via JavaScript, facilitando manutenções e atualizações estruturais.

## 💻 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3 / Flexbox / Grid**: Estilização moderna e layout 100% responsivo para todos os dispositivos.
- **JavaScript (Vanilla)**: Lógica para animações (reveal), manipulação do DOM e injeção de dados.
- **EmailJS**: Integração no formulário de contato para envio direto de e-mails, sem necessidade de backend complexo.

## 📁 Estrutura do Projeto

- `index.html`: Arquivo principal da aplicação.
- `assets/css/`: Diretório contendo todas as folhas de estilo (reset, base, responsividade).
- `assets/js/`: Scripts para animações, formulário de e-mail e manipulação da interface.
- `assets/data/`: `placeholders.js` onde estão concentrados os dados exibidos no site (Skills, Projetos, Links).

## 🛠️ Como Executar o Projeto

Como é um projeto puramente front-end (arquivos estáticos), a execução é muito simples:

1. Faça um clone do repositório:
```bash
git clone https://github.com/Abraao-SPX/Abraao-SPX.github.io.git
```

2. Acesse a pasta do projeto e abra o arquivo `index.html` em seu navegador de preferência.

Se desejar, você pode utilizar a extensão **Live Server** no VSCode para rodar com auto-reload durante o desenvolvimento ou usar os scripts locais `.bat` / `.ps1` (se possuir o ambiente configurado).
